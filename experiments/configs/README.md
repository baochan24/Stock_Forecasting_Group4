# experiments/configs

Hai cấu hình `lstm_one_step_baseline.yaml` và `lstm_multi_step_baseline.yaml` dùng cùng snapshot, scaler và bộ cửa sổ AAPL của TV2. Horizon lần lượt là 1 và 5, lookback 30, batch size 32. Chạy `scripts/check_tv4_aapl_data.py` bằng môi trường TV4 để kiểm tra cả hai. Cấu hình thực nghiệm cuối cùng sẽ được chọn ở mục 7.
