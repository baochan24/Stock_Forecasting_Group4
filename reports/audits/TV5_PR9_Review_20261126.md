# Audit TV5 trước triển khai

Ngày 26/11/2026. Kiểm tra GitHub PR #9 và checkout riêng nhánh TV5, head edc2bd953c7644040f4142a545316377cd143e13. PR đang open, chưa merge và không thay đổi so với audit trước. Checkout sau kiểm tra sạch. Phạm vi lần này là audit và lập công việc, chưa tiếp nhận source vào backend workspace chính.

## Đã có và dùng được

CNNOneStep với hai Conv1d, ReLU, MaxPool, Dropout và hai Linear. Input mặc định (B,30,1), output (B,1), có get_config/from_config và đếm tham số. Tổng thực tế 17.057 tham số. Chạy tests nguyên source trong môi trường TV4 sạch hiện có, 7/7 đạt. Đây là bằng chứng model trên dữ liệu tổng hợp.

## Phát hiện cần xử lý

- CNN mặc định float32, dữ liệu TV2 và đường LSTM hiện dùng float64. Probe đưa input float64 vào CNN gây RuntimeError. Dtype CNN/adapter cần chốt tường minh, đề xuất float64 để giữ cùng điều kiện với LSTM.
- Config vẫn cho output_size=5 và tạo output (2,5). Cần khóa contract CNN một bước và một feature, kiểm kiểu/số dương của tham số, dropout và khả năng pooling.
- NaN input đi qua model thành NaN output. Cần kiểm dữ liệu hữu hạn tại boundary phù hợp, kết hợp finite guards trong trainer.
- Tests hiện thiếu batch cuối B1, gradients hữu hạn, Adam update, dropout train/eval và state_dict roundtrip từ file thật.
- Runner/factory AAPL hiện mặc định tạo LSTM; validate_aapl_config chỉ nhận hai model_type LSTM. Nhận nhãn cnn_one_step ở config parser chưa đủ để chạy CNN end-to-end.
- Callback persistence hiện gọi save_lstm_checkpoint, helper chỉ hỗ trợ hai LSTM. Cần checkpoint CNN có config/dtype/provenance/checksum và reload.
- Chưa có YAML CNN, artifacts/run logs chính thức, checkpoint được chọn bằng validation hay kết quả ba seed.
- PR ghi đè báo cáo triển khai chung bằng phần CNN. Khi tiếp nhận cần ghép thành mục, giữ phần TV3/TV4.

## Flow TV5 sau TV4

| Mục | Công việc cần hoàn thành | Điều kiện nghiệm thu |
|---|---|---|
| 1 | Tiếp nhận source CNN đúng module | Model, tests và phần báo cáo được tích hợp chọn lọc, baseline tests chạy trong workspace; tạo notebook TV5 |
| 2 | Chốt kiến trúc, dtype và contract | Input (B,30,1), output (B,1), CPU, dtype rõ ràng, ghi Decision Log và ngân sách |
| 3 | Nối bộ dữ liệu TV2 dùng so sánh | Cùng scaler/version và 1.954 mẫu train, 250 validation như LSTM lookback 30; đối chiếu ngày/ID và X/y |
| 4 | Nghiệm thu cấu hình/model | Kiểm cấu hình sai, finite inputs/outputs/gradients, batch B1, Adam update, dropout, lưu/nạp weights |
| 5 | Nối factory/config vào loop TV4 | Tạo đúng CNN, YAML hợp lệ, Adam/MSE, weighted loss, early stopping và log dùng chung |
| 6 | Lưu/nạp checkpoint CNN | Config tái tạo model, hash nguồn/scaler/data/run/seed/best epoch, lựa chọn bằng validation, reload instance mới |
| 7 | Smoke AAPL và đo CPU | Run giới hạn trên dữ liệu thật, kiểm loss và reload, đo train/validation/inference với điều kiện rõ ràng |
| 8 | Thực nghiệm chính thức ba seed | Chốt 42/123/456 và ngân sách trước run, lưu cả ba best checkpoint, curves/TensorBoard, mean/std ddof=1 |
| 9 | Phối hợp TV6 so CNN/LSTM/persistence | Cùng ngày/mẫu đánh giá, MAE/RMSE USD, cùng điều kiện CPU, phân tích sai số và giới hạn |
| 10 | Audit, tái lập và bàn giao | Lock, source/config/tests/notebook, package checksum, verifier độc lập và ghi riêng xác nhận máy người nhận |

CNN có khoảng 3,78 lần tham số của LSTM một bước (17.057 so với 4.513). Cần báo khác biệt và ngân sách tuning; không yêu cầu số tham số bằng nhau. Các seed và ngân sách CNN được ghi trước thực nghiệm, không chọn dựa test.

TV4 đã hoàn thành local nên phụ thuộc loop không còn chờ sửa. Mục 5/6 của TV5 cần mở rộng factory và persistence cho CNN. TV6 sở hữu module metric và đánh giá test; TV5 bàn giao model/run và phối hợp so sánh theo contract.
